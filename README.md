# Ridge of the Ringworld

A lone astronaut stands on a rugged ridge beneath the sweeping rings of a
colossal gas giant. The low, cinematic light catches the rock and spacesuit
against the planet's immense shadow.

The shipped JPEG is stored as entry.png. The Node program checks its JPEG
signature, size, frame dimensions, and ending marker before copying it into
the output directory and reporting its dimensions and SHA-256 digest.
